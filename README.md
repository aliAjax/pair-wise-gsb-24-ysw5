# hxwl-10 考古探方记录

遗址探方、地层关系、跨探方接口与出土物归属档案。

## 技术栈

React + Vite + TypeScript + CSS（localStorage 本地持久化，无需后端）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5110。`npm run build` 可做生产构建与全量类型检查。

## 地层关系整理台功能

针对「跨探方接口关系和遗迹打破关系分开记、成环后难回查」的整理场景：

- **同一遗迹集中登记关系**：在单位详情中统一维护与其他单位的
  上下**叠压**、**打破**（带方向：上层/打破者为晚）和**共存（同期）**关系。
- **成环拦截与回查**：保存叠压 / 打破前在「拟保存」状态下跑时序成环检测；
  一旦成环即拦住保存，告警中列出环上涉及的**探方、地层/遗迹单位**，
  并逐段回查构成环的**原关系**（类型、两端、依据、登记时间），
  本次拟新增的边标记为「已拦截、未写入档案」。
- **跨探方接口三项比对**：接口两端必须分属不同探方，登记后进入**待核区**；
  只有**土质土色、包含物、陶片组合**三项完全对应才能确认同期，
  确认后自动生成来源为「接口确认」的共存关系；任一不符则继续留在待核区，
  待核数量在标签页上有角标提醒。
- **出土物归属与修订留痕**：出土物必须归入一个具体地层 / 遗迹单位；
  修订归属时强制填写更正原因，系统保留完整归属链
  （原归属 → 新归属、原因、时间，初次登记也在链上）。
- **按探方和状态查找**：探方 / 状态筛选同时作用于单位与出土物列表；
  关系总览提供全库时序体检、关系总表和按探方汇总。
- **重新打开继续标注**：档案数据、筛选条件、当前标签页和选中单位
  都保存在浏览器 localStorage，刷新或重开页面自动恢复。

## 目录结构

- `src/types.ts` — 领域模型（单位、有向关系、共存、接口、出土物修订）
- `src/logic.ts` — 时序成环检测、原关系回溯、接口三项比对
- `src/store.ts` — `useArchive` 数据与操作 hook、持久化
- `src/seed.ts` — 示例档案
- `src/components/` — 整理台、接口待核区、出土物台账、关系总览四个视图
